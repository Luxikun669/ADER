# ADER

Official implementation of **"Adaptive Depth and Expert Refinement for Efficient Speech Enhancement"**.

ADER is an efficient speech enhancement framework that combines **adaptive-depth inference** and **expert-based refinement** to dynamically allocate computation according to the input, aiming to achieve a better trade-off between speech enhancement performance and computational efficiency.
